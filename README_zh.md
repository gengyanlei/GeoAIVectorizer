## 1-地质类栅格图像智能矢量化软件(GeoAIVectorizer v1.0) 简介
* GeoAIVectorizer软件源于中国某省地勘基金研究项目成果: (2022年预研, 2023年立项, 2024年执行);
* 软件核心理论算法: 2023年地质类ocr模型、线提取矢量化; 2024年地质类ocr数据集、模型、文本点、符号点、优化线提取矢量化;
* 软件功能: 文本检测识别、符号检测识别、文本点矢量化、符号点矢量化、线矢量化、面矢量化(弱);


## 2-应用
* 中国地质调查局某些单位
* 中国各省地质单位
