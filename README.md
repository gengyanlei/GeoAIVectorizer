## 1. Introduction to the Intelligent Vectorization Software for Geological Raster Images (GeoAIVectorizer v1.0)
* The GeoAIVectorizer software originates from the results of a geological exploration fund research project in a Chinese province (pre-research in 2022, project initiation in 2023, and execution in 2024).
* Core theoretical algorithms of the software:
  * 2023: Geological OCR model and line extraction vectorization.
  * 2024: Geological OCR dataset, models, text point and symbol point processing, optimized line extraction vectorization.
* Software functions: Text detection and recognition, symbol detection and recognition, text point vectorization, symbol point vectorization, line vectorization, and (weak) polygon vectorization.


## 2. Application
* Certain units of the China Geological Survey (CGS)
